# Next tasks manager

### Frontend: Next.js, React e TypeScript.

### Estilização: Tailwind CSS e shadcn/ui.

### Funcionalidades: criar, listar, editar, excluir e concluir tarefas.

### Filtros: todas, pendentes e concluídas.

### Persistência: inicialmente LocalStorage; depois, API com Laravel ou banco de dados.
